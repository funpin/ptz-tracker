# L1/R1 — скорость стика, крупность — свайпом по тачпаду

Пользователь, 2026-11-06: L1/R1 меняют скорость стика, который поворачивает камеру. Что именно они меняют, выбирается у каждого геймпада в ☰ → «Геймпады…». Крупность (пояс / в рост / общий) переходит на свайп по тачпаду. Отклик — вибрация по шагам.

## Как будет для оператора

- **R1 — быстрее, L1 — медленнее.** Действует только на поворот и наклон от этого геймпада. Зум на курках, мышь и стрелки не меняются.
- **Режим L1/R1** выбирается у каждого геймпада в ☰ → «Геймпады…». По умолчанию — «Предел скорости».
  - **«Предел скорости»** (переключение ступеней) — полный наклон стика даёт 25 / 50 / 75 / 100 % скорости камеры. По умолчанию 100 % (как сейчас).
  - **«Чувствительность»** — тот же ползунок «Плавно ↔ Резко» этого геймпада, шаг 10.
- **Вибрация.** У «Предела скорости» число коротких толчков равно номеру ступени (1–4). У «Чувствительности» шаг отмечается одним толчком. На краю — длинный толчок «некуда», как сейчас у упора.
- Ступень и чувствительность запоминаются у каждого геймпада (по его id, как чувствительность в 1.1) и переживают перезапуск.
- **Крупность — свайп по тачпаду:** вправо — шире (пояс → в рост → общий, как прежний R1), влево — ближе. Как и раньше, действует, только если камера этого геймпада выбрана в окне; иначе — вибрация «некуда».
- **Нажатие на тачпад — по-прежнему Стоп.** Свайп определяется так: палец прошёл по горизонтали не меньше трети ширины тачпада и не дольше 0,8 с, по горизонтали больше, чем по вертикали, и тачпад при этом не нажимали. Короткое касание и нажатие свайпом не считаются.

## Устройство

- `gamepad/device.py`: `RawPad.touch` — `(x, y)` первого пальца или `None`. Читается через `SDL_GameControllerGetTouchpadFinger` из того же потока опроса (проверено пробником на DualSense 2026-11-06: x 0…1, свайп 0,1–0,4 с). Сбой чтения — `None` и одна строка в журнал.
- `gamepad/mapping.py`: L1/R1 → новое намерение `SpeedStep(±1)` (вне меню). Свайп → `Composition(-1)` вправо и `Composition(+1)` влево. Распознавание — чистая функция по времени, в `Mapper`.
- `GamepadBridge`: `set_speed_limit(frac)` умножает поворот и наклон из `velocity()`; зум не трогает.
- `MainWindow._on_pad_intents`: `SpeedStep` по режиму геймпада — ступень (`cfg.pad_speed_gear[id]` ∈ 1…4) или чувствительность (`cfg.pad_sensitivity[id]` ± 10). Вибрация, сохранение настроек, обновление окна «Геймпады».
- `config.py`: `pad_l1r1_mode: dict[id → "limit"|"sens"]`, `pad_speed_gear: dict[id → 1…4]`. Неверные значения при чтении отбрасываются, как у `pad_sensitivity`.
- Окно «Геймпады»: у строки геймпада — выбор «L1/R1: Предел скорости / Чувствительность» и текущая ступень.
- Тексты: окно клавиш (F1), `docs/OPERATOR.md`, `docs/LIVE_TEST_PROMPT.md`, спека геймпада; CHANGELOG `[Не выпущено]` — MINOR (1.2.0).

2. `SdlBackend`: чтение пальца тачпада в `RawPad.touch`, сбой → `None` (подставная SDL).
3. `config`: новые поля, чтение и отбраковка мусора.

5. `MainWindow`: `SpeedStep` в обоих режимах, края с «некуда», вибрация по ступени, сохранение, свайп меняет крупность только на выбранной камере.
6. Окно «Геймпады»: выбор режима у каждого геймпада, сохраняется.
7. Тексты и документация; быстрый и полный наборы тестов; проверка на DualSense у пользователя (камера не в эфире).
