# План: чувствительность ручного управления и крестовина без «Авто» (версия 1.1)

Спека: `docs/superpowers/specs/2026-11-05-control-sensitivity.md` (решения пользователя 2026-11-05). Код — только после «да» пользователя. Ветка — `main` (четыре камеры уже влиты). Дизайн-сессия правит соседние места окна: строку под стиком и окно «Геймпады…» делаем здесь, с ней согласуем.

## Как это будет работать для оператора

- Под экранным стиком — строка **«Чувствительность: Плавно ━━●━━ Резко»** и флажок **«Медленнее на крупном плане»**. Касается мыши и стрелок.
- ☰ → **«Геймпады…»**: список всех геймпадов, которые программа видела (имя, номер клетки по огонькам, подключён ли сейчас), у каждого свой ползунок «Плавно ↔ Резко». Изменения действуют сразу. Флажок «Медленнее на крупном плане» общий.
- Полный наклон стика по-прежнему даёт полную скорость; «Плавно» — мягче около центра, легче сделать маленький поворот.
- Крестовина ←/→ (ирис) и ↑/↓ (gain) на «Авто»: первое нажатие выключает «Авто». Ирис сразу делает шаг от текущего положения; gain встаёт на последнее ручное значение, которое программа видела, иначе на 0 dB. Флажки «Авто» в панели снимаются сразу.

## Задачи (TDD: сначала тест, который падает)

1. **Кривая стика** — чистая функция `control/manual_curve.py::shape(v, sens)`: `sens` 0…100 (0 — «Плавно», 100 — «Резко»), степень `e = 3 − 2·sens/100` (1 — как сейчас, 3 — очень мягко у центра), знак сохраняется, `shape(±1) = ±1`, монотонна. По умолчанию `sens = 50` (e = 2). Тесты: границы, монотонность, знак, ноль. Причина и числа — в `docs/DECISIONS.md`.
2. **Настройки** — `AppConfig.stick_sensitivity: int = 50`, `slow_on_tele: bool = True`, `pad_sensitivity: dict[str, int] = {}` (ключ — опознаватель геймпада). Старый `config.json` читается, неверные значения обрезаются в 0…100. Паролей тут нет.
3. **Опознаватель геймпада** — в `gamepad/device.py` серийный номер через `SDL_GameControllerGetSerial` (ctypes, как уже читается заряд); нет серийного — `GUID:имя`. Отдаётся в `info()["id"]`. Тест на фальшивом SDL: серийный есть / нет. В окне «Геймпады…» для геймпадов без серийного — пометка «одинаковые геймпады без серийного номера делят настройку».
4. **Применение кривой** — мышь (экранный стик), клавиши (скорость стрелок `KEY_PAN_SPEED` через ту же кривую) и каждый геймпад (`Mapper` после мёртвой зоны, своя `sens` по опознавателю) — до смесителя `multicam/velocity.py`. Зум и фокус кривая не трогает. Тест в виртуальном времени: при `sens = 0` половина наклона даёт четверть скорости и меньше кода `#PTS`, при 100 — как сейчас.
5. **«Медленнее на крупном плане»** — множитель `hfov(зум)/hfov(широкий)`, не меньше 0,15, через `he42.hfov_deg` по известному положению зума сессии; применяется только к ручному повороту (`set_pan_tilt_velocity` из смесителя), регулятор слежения его не видит — проверить тестом, что слежение шлёт прежние коды. Тест: на теле тот же наклон даёт меньший код, на широком — прежний.
6. **Крестовина снимает «Авто»** — `CameraSession.iris_step` / `gain_step`: сначала тест на симуляторе, воспроизводящий жалобу «ирис с крестовины не снимает авто» (если воспроизводится — чинить; если нет — тест остаётся сторожем). Gain из AUTO: первое нажатие — `_last_manual_gain`, иначе `GAIN_CODES[0]` (0 dB), без шага; вибрации «некуда» больше нет. Флажки «Авто» в правой панели обновляются по снимку состояния.
7. **Интерфейс** — строка под стиком (`manual_controls.py`), окно `ui/gamepads_dialog.py` (пункт ☰ «Геймпады…»), справка F1 и `docs/OPERATOR.md`. Правая панель помещается в 1640×850 (тест `test_side_panel_fits_without_scroll`, запас ≥ 40 px под Windows).
8. **Документы и выпуск** — строки в `CHANGELOG.md` → `[Не выпущено]` (по умолчанию стик мягче, чем в 1.0.1 — сказать), `DECISIONS.md` (кривая, 0 dB из авто), полный `pytest`, независимое ревью ветки (Sonnet), затем — по согласию пользователя — версия 1.1.0 вместе с четырьмя камерами.

## Что не входит

- Скорость зума и фокуса с геймпада (только поворот/наклон).
- Своя кривая для каждой камеры (кривая — у источника: мышь/клавиши или геймпад).
- Зоны мышью и ползунок крупности — версия 1.2 (дизайн-сессия).
