# Чувствительность ручного управления и крестовина без «Авто»

Согласовано с пользователем 2026-11-05. Делается после слияния ветки «до 4 камер» (в ней несколько геймпадов сразу, `multicam/pads.py`), выходит вместе с ней в 1.1. План задач — отдельно, до кода, с одобрением пользователя.

## Что не так сейчас

- Стик геймпада и экранный джойстик реагируют слишком резко: после мёртвой зоны кривая линейная (`gamepad/mapping.py::_dz`), скорость камеры — `velocity_to_code` линейно до кода 49.
- Крестовина вверх/вниз (gain) из «Авто» ничего не делает, если программа не видела ручного значения (`CameraSession._gain_apply` → False, вибрация «некуда»). Пользователь сообщил, что авто ирис с крестовины тоже не снимается — проверить на симуляторе и тестом; по коду `iris_step` снимает авто после ответа камеры на `#QRS`.

## Решения пользователя

1. **Ползунок «Чувствительность»** (Плавно ↔ Резко):
   - мышь и клавиши-стрелки — строка под экранным стиком в правой панели, одна настройка на программу;
   - каждый геймпад — свой ползунок в окне ☰ → «Геймпады…»: список всех геймпадов, которые программа видела, с их настройкой. Узнавать геймпад по серийному номеру SDL, если он есть; иначе — по GUID и имени (два одинаковых без серийного номера будут делить настройку — сказать об этом в окне).
   - Смысл ползунка: форма кривой «наклон стика → скорость» (степень от линейной до плавной у центра); полный наклон по-прежнему даёт полную скорость.
2. **«Медленнее на крупном плане»** — переключатель рядом с чувствительностью: на теле тот же наклон стика поворачивает камеру медленнее (по углу обзора из модели камеры), чтобы кадр не улетал. Касается мыши, клавиш и геймпадов.
3. **Крестовина снимает «Авто»:**
   - влево/вправо (ирис): если ирис на авто — выключить авто и сделать шаг от текущего положения;
   - вверх/вниз (gain): если gain на авто — первое нажатие только выключает авто и ставит последнее ручное значение, которое программа видела; если не видела — 0 dB. Картинка может стать темнее, если авто поднимал gain: это принято.
   - Флажки «Авто» в правой панели сразу показывают новое состояние.

## Инварианты

- Чувствительность меняет только ручное управление; регулятор слежения её не видит.
- Ручное движение по-прежнему выключает слежение и флажки агента до первой команды.
- Настройки хранятся в `config.json` (не пароли), старый `config.json` читается без ошибок. По умолчанию — средняя плавность (мягче, чем сейчас); об этом строка в CHANGELOG.
