Справка F1 — кнопки в списке той же формы, что на геймпаде

Вместо серых плашек с текстом («R1 / L1», «× ○ □ △») — маленькие кнопки как на рисунке слева: курки, бамперы, стики, крестовина, тачпад, Options, Create, PS. Наведите на строку — подсветится она и кнопки на геймпаде; наведите на кнопку геймпада — подсветится строка и только эта кнопка в ней (например, один △ из четырёх).

Рисунок — как сейчас в программе, упрощённо.
  1. 1 Форма кнопки повторяет геймпад: бампер — плоская полоска, курок — выше и скруглён сверху, стик — кружок с ободком, крестовина — крестик с нужными стрелками, тачпад — широкий прямоугольник (у свайпа — со стрелкой), Options/Create — узкие «таблетки», PS — кружок.
  2. 2 Подсветка как сейчас — лаймом с заливкой 22 % (брендбук §7), но по одной кнопке: навели на △ на геймпаде — горит только △ в строке пресетов.
  3. 3 Стики — одной строкой: движение и нажатие (L3 / R3) вместе; подписаны L и R (в списке — буквой в кружке, на рисунке — «L-стик · L3», «R-стик · R3»). Анимации: левый стик крутится по кругу, правый качается влево-вправо, по очереди с нажатием; кнопки, крестовина и курки «нажимаются»; по тачпаду при свайпе проходит лаймовый палец. Пресеты — двумя рядами по номерам: ✕ 1 ○ 2 / □ 3 △ 4. Свайп — на тачпаде рисуются стрелки «ближе ← → шире».
  4. 4 Тексты обновлены: L1/R1 — 8 ступеней 3–90 °/с; свайп по тачпаду; Options — включить/выключить камеру и сцена; PS — открыть справку (если главная сессия подтвердит, что кнопку не перехватывает система).
