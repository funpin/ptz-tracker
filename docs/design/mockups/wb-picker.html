Баланс белого: выбор режима

Сейчас — большое поле со стрелкой в отдельном отсеке; на Windows этот отсек рисуется системным. Ниже — две замены в той же строке «WB». Режимов семь: ATW, AWB A, AWB B, ATW 2, 3200K, 5600K, VAR. Ползунок температуры работает только в VAR.
