Геймпады, TRACK, пустые клетки и проверка функций

1. Геймпады с зарядом в батарейке

Процент — прямо внутри батарейки, как в iOS. Белая заливка — обычно; ≤ 20 % — оранжевая; ≤ 10 % — красная; заряжается — лаймовая. Номер рядом совпадает с огоньками на геймпаде. На одной камере может быть несколько геймпадов: до двух — показываем оба, больше — первый и «+2» (наведите — список).

Мало заряда, 18 % 2 18
Заряжается, 46 % 3 ⚡46
Два геймпада на одной камере 🎮︎1 83🎮︎3 52
Четыре на одной камере (редко) 🎮︎1 83+3
Верхняя строка: всего геймпадов 🎮︎ 3 18— показываем самый разряженный

2. Кнопка TRACK при нескольких камерах

Кнопка всегда про выбранную камеру (Пробел), её цвет — состояние выбранной. Справа внутри кнопки — маленькие квадратики только тех камер, у которых включён анализ (по умолчанию одна — тогда квадратик один и кнопка выглядит как сейчас). Квадратик: лаймовая цифра — ведёт; оранжевая — потерял цель; контур — анализ идёт, но слежение выключено. Клик по квадратику — включить/выключить слежение той камеры, не переключая выбор. Esc — стоп всех.

3. Пустые клетки

Пустая клетка сама показывает полезный служебный вид (выбор — в ▾ шапки): при 3 камерах — «Сводка», при 2 — «Сводка» и «Положение камер». Если камер нет совсем — приветствие с логотипом. «Графики PTZ» остаются в списке для разбора.
