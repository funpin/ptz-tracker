# PTZ Tracker

Программа для Windows, которая управляет PTZ-камерами Panasonic AW-HE42 по сети и в будущем будет сама плавно вести докладчика.

**Текущий этап (1):**
- список камер с запоминанием;
- видео с камеры по сети;
- ручное управление: поворот, зум, фокус, ирис, пресеты;
- **диагностика камеры** — нужна, чтобы настроить слежение под ваши реальные камеры;
- виртуальная камера-симулятор для отладки без живой камеры.

Дизайн и планы лежат в [`docs/superpowers/`](docs/superpowers/).

## Диагностика камеры на площадке

Это первое, что нужно сделать с реальной камерой. Диагностика ничего не настраивает в камере, она только измеряет её поведение и собирает отчёт.

1. Скопируйте папку `PTZTracker` (из архива `PTZTracker-win64.zip`) на компьютер, который находится в одной сети с камерами.
2. Запустите **`PTZTracker-diag.exe`** двойным кликом.
3. Введите IP камеры (по умолчанию `10.0.0.12`) и нажмите Enter.
4. На вопрос «Продолжить с движением?» ответьте:
   - **`д`** — только если камера **не в эфире**. Камера сделает несколько небольших поворотов и наездов и вернётся на место. Это займёт около минуты.
   - **`н`** — если сейчас эфир. Тогда проверятся только связь и видео.
5. Когда появится надпись **«Подвигайте камеру ПУЛЬТОМ»**, в течение 15 секунд подвигайте эту камеру с пульта влево-вправо и зумом, затем отпустите.
6. Если Windows спросит разрешение на доступ к сети для `PTZTracker-diag.exe`, нажмите **«Разрешить»**. Камера присылает уведомления на компьютер, и без разрешения они не дойдут.
7. На рабочем столе появится файл `ptz-diag-10.0.0.12-….zip`. **Пришлите его разработчику.**

Если на камере включён логин и пароль, запустите из командной строки:

```bat
PTZTracker-diag.exe --ip 10.0.0.12 --user admin --password ваш_пароль
```

Пароль в отчёт не попадает: в архиве он заменяется на `***`.

То же самое можно сделать из основной программы: **Сервис → Диагностика камеры…**

## Основная программа

Запустите `PTZTracker.exe`.

- **Камера:** выберите камеру из списка. Кнопки «Добавить», «Изменить», «Удалить» управляют списком (название, IP, логин и пароль, при необходимости адрес RTSP). Кнопка «Проверить связь» показывает, отвечает ли камера.
- **Видео:** адрес потока подбирается автоматически (перебираются известные варианты Panasonic, рабочий запоминается). Если видео нет совсем — проверьте в веб-интерфейсе камеры, что включена передача H.264/RTSP, или впишите адрес вручную в «Изменить».
- **Поворот:** тяните ручку джойстика мышью; когда отпускаете, камера останавливается.
- **Зум:** ползунок «Шире ↔ Ближе»; когда отпускаете, зум останавливается.
- **Фокус и ирис:** автоматический или ручной режим.
- **Пресеты 1–9:** клик вызывает пресет, Shift+клик записывает текущее положение.
- **Клавиши:** стрелки — поворот, `+`/`−` — зум, **Esc — немедленный стоп**.

Настройки хранятся в `%APPDATA%\PTZTracker\config.json`, пароли — в диспетчере учётных данных Windows. Логи пишутся в `%LOCALAPPDATA%\PTZTracker\Logs`.

## Сборка `.exe`

Собрать программу можно двумя способами.

**На любом Windows-компьютере с Python 3.12:**

1. Установите Python 3.12 с [python.org](https://www.python.org/downloads/).
2. Скопируйте папку проекта и запустите `build.bat`.
3. Результат появится в `dist\PTZTracker\` и в архиве `dist\PTZTracker-win64.zip`.

**Через GitHub** (после подключения репозитория): каждый push запускает сборку `.github/workflows/windows-build.yml`. Готовый архив `PTZTracker-win64` скачивается во вкладке **Actions**.

## Для разработки (macOS/Windows)

```bash
python3 -m venv .venv
.venv/bin/pip install -e ".[dev]"
.venv/bin/python -m ptztracker --sim     # окно с виртуальной камерой
.venv/bin/pytest -q                      # тесты (около 2 минут)
```

Виртуальная камера «Симулятор» понимает те же команды, что AW-HE42, двигается с инерцией и отдаёт видео синтетической сцены с идущим докладчиком. Вместо синтетической сцены можно подставить свою запись общего плана: поле `sim_scene_path` в `config.json`.
