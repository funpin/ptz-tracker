# Правила участия

## Устройство

| Путь | Что там |
|---|---|
| `src/ptztracker/camera/` | команды Panasonic, HTTP, очередь команд, сессия камеры, замеры HE42 (`he42.py`) |
| `src/ptztracker/video/` | приём кадров MJPEG/RTSP |
| `src/ptztracker/vision/` | детектор позы, сопровождение и цель, фоновый анализ |
| `src/ptztracker/control/` | модель камеры, композиции, регулятор, слежение, мастер калибровки |
| `src/ptztracker/recorder/` | чёрный ящик, чтение и повтор эпизодов |
| `src/ptztracker/api/`, `lab.py` | локальный API и команды без окна для агента |
| `src/ptztracker/tally/` | Tally ATEM (только отображение) |
| `src/ptztracker/sim/` | виртуальная AW-HE42 |
| `src/ptztracker/ui/` | окна Qt; цвета — только в `theme.py` |
| `tests/` | быстрые тесты и медленные (`slow`) в реальном времени на симуляторе |
| `packaging/`, `build.bat` | сборка `.exe` |
| `docs/` | архитектура, решения, бэклог, спеки и планы |

## Инструменты и проверки

Python 3.12–3.13:

```bash
python3 -m venv .venv && .venv/bin/pip install -e ".[dev]"
.venv/bin/ruff check src tests
.venv/bin/pytest -q -m "not slow"   # после каждого изменения
.venv/bin/pytest -q                 # перед коммитом этапа
```

## Как вести работу

- **Новая функция:** обсуждение → спека → план в `docs/superpowers/` → TDD задачами → ревью. План одобряет пользователь до кода.
- **Сначала тест, который падает.** Поведение регулятора проверяется сначала в виртуальном времени (`tests/control/loop.py`), затем на симуляторе (`@pytest.mark.slow`).
- **Факты живой камеры** — только в §7 спеки и в `camera/he42.py`.
- **Порог или коэффициент** меняется только по замеру: причина и цифры — в `docs/DECISIONS.md`.
- **Инварианты эфира** (`docs/ARCHITECTURE.md`) держат тесты; их не ослабляют.
- **Пароли** не попадают в логи, на экран, в отчёты и записи. Настоящие `config.json`, отчёты диагностики и записи чёрного ящика с площадки в репозиторий не кладутся — это проверяет `tests/test_repository_hygiene.py`.

Интерфейс, комментарии и документация — на русском. Коммит объясняет, зачем нужно изменение, и касается одной темы.
